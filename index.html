Mac Keyboard for Windows

Use an Apple Magic Keyboard on Windows the way you would on a Mac. ⌘C, ⌘V, ⌘Tab, ⌥ word jumps, brightness and media keys — they just work.

Download for Windows

Free · One small .exe · Windows 10 and 11 · All versions

Setup

  1. Download MacKeyboard.exe and move it somewhere permanent, like Documents.
  2. Double-click it and choose Yes on the admin prompt. An icon appears in the tray.
  3. Restart your PC once when it asks — that's when ⌘ starts acting like a Mac's.
  4. Done. It starts with Windows from now on (turn that off from the tray icon).

Windows may show a “Windows protected your PC” warning because the app isn't signed. Click More info → Run anyway.

Switch keyboards anytime

Plugging in a regular Windows keyboard? Right-click the tray icon and pick Keyboard: Regular Windows keyboard. Mac shortcuts turn off and ⌘ is the Windows key again — no restart. Pick Keyboard: Magic Keyboard to switch back.

Keep the app running: ⌘ only works while it's open. Use Windows mode instead of quitting.
